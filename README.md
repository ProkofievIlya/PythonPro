# Кінотека (Lesson 6)

Навчальний веб-додаток на Flask: головна сторінка, список фільмів і форма додавання нового запису.

Дані зберігаються у файлі `films.json`, тому список не зникає після перезапуску сервера.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Після цього відкрийте в браузері: [http://127.0.0.1:5000](http://127.0.0.1:5000)

Зупинити сервер: `Ctrl+C`.

## Маршрути

| Адреса | Що показує |
|---|---|
| `/` | головна сторінка |
| `/films` | список фільмів |
| `/films/add` | форма додавання фільму |
| `/about` | сторінка про проєкт |

Неіснуюча адреса відкриває сторінку 404.

## Структура

```
.
├─ app.py              # маршрути, валідація форми, робота з JSON
├─ films.json          # збережена колекція фільмів
├─ requirements.txt    # залежності (Flask)
├─ static/
│  └─ style.css
└─ templates/
   ├─ base.html        # спільний каркас
   ├─ index.html       # головна
   ├─ items.html       # список фільмів
   ├─ add.html         # форма
   ├─ about.html       # про проєкт
   └─ 404.html
```

Шаблони наслідують `base.html`. Стилі підключаються там через `url_for('static', filename='style.css')`.
